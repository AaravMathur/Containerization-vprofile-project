Steps to Create a Container
1.Create a virtual macchine with the help of vagrant file.
2.Choose accoring to your machine like (windowsAndMacIntel and macosarm)
3.Run Vagrant file and Install Docker Engine.
4.Go to vagrant file location inside your Virtual machine.
5.Run docker compose build 
6.Run docker compose up -d
7.Run docker compose ps (To check the ports of Dockerfiles).
8.Run ip addr show command to check your ip like <publicip>
9.Go to your browser and type <publicip:80>
10. You can see your website
